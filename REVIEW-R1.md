# Round-1 findings (Codex gpt-6-astra) and author dispositions

1. **High — `autarkeia/skills/librarian/SKILL.md:23–24`: Different originals can overwrite each other.** Two monthly downloads named `statement.pdf` have different hashes, so both pass deduplication and target the same folder and filename. **Smallest fix:** prohibit overwriting an existing destination; preserve both using a dated subfolder or suffix, then verify the copied file’s hash.

2. **High — `autarkeia/skills/librarian/SKILL.md:24–27`; `autarkeia/references/archive.md:23`: Archive routing conflicts with private-project containment.** Filing always targets the vault archive and logs the location centrally. A confidential project document can therefore leave `projects/<name>/`, contrary to `vault-template/AGENTS.md:40`. Delegating memory extraction to distill happens after the copy and register writes. **Smallest fix:** resolve project ownership and read its rules before any write; keep restricted originals, registers and filing details inside that project.

3. **High — `autarkeia/skills/email/SKILL.md:11,33–35`: Email intake still writes about other people without the required yes.** It immediately records “who, subject, what matters,” before distill’s approval checks. This conflicts with the contract’s another-person gate and new per-case reuse rule (`vault-template/AGENTS.md:82,110`). **Smallest fix:** apply those checks before the first log write and obtain approval for the affected entries.

4. **Medium — `vault-template/AGENTS.md:77`: “Ask first only” excludes existing skill-specific approvals.** Filing the user’s own document and fixing ordinary vault structure are reversible internal work, yet librarian and health-check explicitly require approval. Neither exception appears in the contract’s list. **Smallest fix:** add “and approval steps required by the skill being used” to the exceptions.

5. **Medium — `autarkeia/references/layers.md:33–42`: The precedence rules can restore obsolete facts.** A historical signed document always beats a newer conversation, and an old project entry always beats a newer vault entry. That conflicts with both newer-information supersession and “their answer is final.” For example, an old signed lease can override a confirmed move. **Smallest fix:** establish applicability and effective date first; apply provenance ranking only to competing claims about the same period, and explicitly define how confirmed corrections override prior entries.

6. **Medium — `autarkeia/skills/distill/SKILL.md:67`; `autarkeia/references/layers.md:48`: Every unresolved subject must become a task or be declared dropped.** This can manufacture owners and deadlines from exploratory conversation, contradicting sparring’s no-tasks-unless-asked rule and the contract’s no-invented-scope rule. It also provides no truthful state for an unresolved observation. **Smallest fix:** apply the rule to agreed actionable follow-ups; retain other items explicitly as unresolved observations without inventing a commitment or disposal decision.

7. **Medium — `autarkeia/skills/librarian/SKILL.md:23,25`; `vault-template/docs/register.md:3–4`: The register format is incompatible with both old vaults and the shipped template.** Librarian requires six columns including a hash; the template and older registers have four different columns and no hashes. Appending the prescribed row misaligns the table, while hash lookup cannot detect legacy duplicates. **Smallest fix:** update the template and specify how to extend existing registers while preserving rows; compute missing hashes from existing files before duplicate comparison.

8. **Medium — `autarkeia/skills/health-check/SKILL.md:24`: Migrating originals out of `docs/` leaves broken references.** The procedure copies, registers and removes the old file, but does not update `docs/register.md` or memory links pointing to it. This directly affects pre-0.4.4 vaults. **Smallest fix:** update the old register entry to point to the archive location and repair references before removing the source, matching the archive’s own move procedure.

9. **Medium — `autarkeia/skills/librarian/SKILL.md:23`: Duplicate detection prevents approved extraction.** “Point at the existing row and stop” also stops when the existing row says nothing has been extracted, or the user requests additional facts from an already-filed document. This defeats the stated purpose of rereading originals later. **Smallest fix:** skip only the duplicate copy; continue approved extraction from the existing file and update its register entry.

10. **Medium — `vault-template/AGENTS.md:89`; `README.md:82`: Required rules are unavailable through the documented fallback.** The fallback copies only `autarkeia/skills/`, omitting the reference files now required for supersession, precedence and archive filing. A model opening only the vault contract also has no resolvable location for “the plugin file `references/layers.md`.” **Smallest fix:** include references in the fallback installation and document their exact installed location; provide a resolvable contract pointer or a brief local version of the essential rules.

11. **Low — `autarkeia/skills/health-check/SKILL.md:24`: A hash mismatch does not prove the original changed.** The registered hash or path could be wrong; the instruction nevertheless requires that conclusion. This contradicts “a record is a claim.” **Smallest fix:** report “the file does not match its registered hash; cause unverified,” preserving both without repair.
