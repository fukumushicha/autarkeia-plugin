Projects live here, one folder each, made when you ask ("new project ..."), never in advance.

```
projects/<name>/
  AGENTS.md        vault/parent references, plus optional custom rules
  CLAUDE.md        one line: @AGENTS.md
  memory/
    facts.md
    decisions.md
    tasks.md
```

Start in the vault. Open a project for focused work; open the vault for planning across projects and whole-life reflection. New projects get short instructions identifying their vault and parent, shown for approval before creation. Custom rules are optional. A subproject follows the same pattern inside its parent; add a legacy parent’s missing instructions in the same approval, before creating or adding first instructions to the child. Never reference a missing parent file; preserve custom rules. Read the vault contract’s Projects section for the exact text. Project work and full daily notes stay in the project. Parent rules and vault rules always hold; a child may add stricter rules, never loosen them. Older projects without these instructions still work from a vault session.
