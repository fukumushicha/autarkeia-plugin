# Archive

Originals from outside, kept exactly as they arrived: statements, contracts, scans, exports, medical reports. Memory is the summary; this is the evidence. Nothing here is ever edited.

Eight areas, by part of life, each made only when a document for it arrives:

Official documents · Money and tax · Health · Homes · Travel · Companies and projects · Photos and memories · Archive records

Inside an area: the person or thing, then the kind of document. Each area gets its own `register.md` listing every file with a hash.

To file something: drop it in `inbox/` and say **librarian**. Documents you or an AI wrote go to `docs/`, not here.
